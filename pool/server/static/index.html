Join the Puzzle #135 Hunt

Linux (CUDA) Windows (CUDA) macOS (Metal)

⚙️ Step 2 — Run Solo or Join Pool
Solo Mode (100% reward to you)
# Download, make executable, run wget https://github.com/Soumya001/starminer/releases/latest/download/starminer-linux-x64-cuda chmod +x starminer ./starminer --puzzle 135 --kangaroo --gpus 0,1

# Replace with your BTC address as worker name + wallet ./starminer --puzzle 135 --kangaroo --gpus 0,1 \ --pool https://starnetlive.space \ --worker 1YOUR_BITCOIN_ADDRESS \ --wallet-address 1YOUR_BITCOIN_ADDRESS

Frequently Asked Questions
Click a question to expand the answer.
What is Puzzle #135?
Puzzle #135 is part of the 1000 BTC Bitcoin Puzzle Challenge. It holds ~13.5 BTC at address 1BgGZ9tcN4rm9KBzDn7KprQz87SZ26SAMH. Unlike Puzzle #71, the public key was exposed in a partial-spend transaction, making it vulnerable to Pollard's Kangaroo algorithm.
How is this different from Puzzle #71?
  • #71 (your other pool): Address only. No pubkey known. Must brute force. No shortcuts.
  • #135: Pubkey exposed. Kangaroo applies. Search space drops from 2^135 to 2^67.5 — still massive, but tractable with enough GPUs.
What is Pollard's Kangaroo?
It's a mathematical algorithm for solving the Elliptic Curve Discrete Logarithm Problem (ECDLP) when the public key is known. Instead of checking every private key, it uses two "kangaroos" (random walks) that hop around the curve. When their paths collide, the private key is revealed. Complexity is O(√N) instead of O(N).
How does the pool work?
The StarNet Pool shards the Kangaroo search across many workers. Each GPU runs random walks and submits Distinguished Points (special coordinates with leading zero bits) to the server. When a tame DP collides with a wild DP, the server reconstructs the private key. Workers earn shares proportional to their DP contribution.
How long does it take?
One RTX 4090 takes roughly 155,000 years expected time solo. The pool with ~50 workers is closer to 20-30 years expected. However, it's a geometric distribution — you could hit the collision in Hour 1, or never. It's a lottery with better odds than brute force.
Do I need a powerful GPU?
Any NVIDIA GPU with CUDA works, but speed scales with compute power. RTX 3060 Ti+ is recommended. Apple Silicon (M1/M2/M3/M4) works via the Metal backend. CPU is ~10,000 hops/sec — technically possible but impractical.
Is this safe for my GPU?
Yes. StarMiner uses standard GPU compute workloads similar to mining or AI inference. Your GPU will run at full utilization. Monitor temperatures and set power limits if running 24/7. A 35% power limit on Ampere cards is popular for quiet operation.
Can I run multiple GPUs?
Absolutely. Use --gpus 0,1,2 to use all detected cards. StarMiner auto-calibrates batch sizes per GPU. Each GPU adds linear speedup.
What happens if the key is found?
If running solo, you keep 100% of the prize. If running pool, rewards are distributed based on your DP share. The pool operator handles payout verification. If you find the key, import it immediately and sweep the funds to a secure wallet.
